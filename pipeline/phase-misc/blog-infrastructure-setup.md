## Fix Applied (Revision 1)

**build-blog.js `formatDate()` timezone bug:**
- `new Date("2026-03-30")` parses as UTC midnight → "March 29" in US Eastern
- Fixed to `new Date(year, month-1, day)` for local time parsing
- All articles now render correct dates

## How to Add New Articles

1. Create `blog-content/[slug].md` with frontmatter: `title`, `description`, `keywords`, `date`, `pillar`
2. Run `node build-blog.js`
3. Generates `blog/[slug]/index.html`, updates `blog/index.html`, updates `sitemap.xml`
